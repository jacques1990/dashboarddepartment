# Paper-Trading Mindset Decision Chart

A standalone interactive decision chart for practicing trading discipline without real money.

## Run locally

Open `index.html` in any modern browser. No installation or server is required.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will show the public Pages address after deployment finishes.

## Safety

This project is for paper-trading practice and education only. It does not connect to a broker, place orders, or use real money.
